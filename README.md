# 🎓 Student Performance Predictor

A modern full-stack web app that predicts a student’s performance score using machine learning based on study habits and lifestyle inputs.

# 🚀 Features

- Predict student performance instantly  
- Beautiful modern UI (React + Tailwind)  
- Machine learning model (scikit-learn)  
- FastAPI backend  
- Real-time predictions  

# 🧠 How It Works

Users enter:

- Hours studied  
- Previous scores  
- Sleep hours  
- Sample papers practiced  
- Extracurricular activities  

The data is sent to a trained ML model which returns a predicted performance score.

# 🛠 Tech Stack

**Frontend**
- React + Vite + TypeScript  
- Tailwind CSS  

**Backend**
- FastAPI  
- scikit-learn  
- pandas
